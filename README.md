Минималистичный конфиг Neovim 0.12+.

- Использует встроенный пакетный менеджер `vim.pack`.
- Настроены встроенные LSP и автодополнение.
- Сочетания клавиш не конфликтуют с Zellij. Единственное, что придётся
  переопределить, — это `<C-g>`, часто использующееся в Vim и других консольных приложениях, на какое-нибудь другое с Alt (встроенных сочетаний с Alt в Neovim нет).
- Решает проблему с комбинациями, перестающими работать при переключении
  системной раскладки, путём использования встроенной русской раскладки (`Ctrl` + `6` в режиме вставки для переключения).
- Доступные комбинации показываются при вводе части префикса; полный список
  открывается по `<leader>?` (через `which-key.nvim`).
- Для leader используется пробел.
- При запуске nvim без аргументов, автоматически загружаются ранее сохраненная сессия (файл `Session.nvim`).
- Настройки разнесены по разным файлам. Базовые лежат в `lua/config` и подключаются вручную в `init.lua`, а настройки сторонних плагинов — в `plugin` (загружаются автоматически после `init.lua`). Конфигурации LSP расположены в `after/lsp` и `lsp`. В первом случае настройки сервера (имя должно совпадать с его названием) рекурсивно объединяются, а во втором — переопределяются.
- Для установки серверов используется `:Mason`. Большинство из них подхватываются автоматически.
- Поддерживаются языки: Bash, Lua, Vim, Python, JS/TS, Rust, Go, HTML/CSS и другие.
- Для форматирования используется `conform.nvim`. Его применение оправдано тем, что не все средства форматирования работают через LSP.
- Для возможностей Treesitter (подсветка, сворачивание и т.п.) при первом
  запуске нужно выполнить `:TSInstall all`.
- Markdown частично рендерится (например, с помощью `render-markdown.nvim`).
- В качестве файлового менеджера используется `oil.nvim`, позволяющий создавать, переименовывать и удалять файлы прямо в буфере.
- Для поиска по файлам и их содержимому используется `fzf-lua`. Для этого установите fzf.
- Для работы с git добавлен `neogit`.
- Требуется Nerd Font для отображения иконок и других специальных символов.

Этот конфиг можно взять за основу своего.
