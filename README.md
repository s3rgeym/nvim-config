### Описание

Минималистичный конфиг Neovim 0.12+ со сл. особенностями:

- Использует встроенный пакетный менеджер `vim.pack`.
- Настроены встроенные LSP и автодополнение.
- Сочетания клавиш не конфликтуют с Zellij. Единственное, что придётся
  переопределить, — это `<C-g>`, часто использующееся в Vim и других консольных приложениях, на какое-нибудь другое с Alt (встроенных сочетаний с Alt в Neovim нет).
- Решает проблему с комбинациями, перестающими работать при переключении
системной раскладки, путём использования встроенной русской раскладки. Для переключения встроенной раскладки используйте `<C-^>` (`Ctrl` + `6`).
- Доступные комбинации показываются при вводе части префикса; полный список
  открывается по `<leader>?` (через `which-key.nvim`).
- Для leader используется пробел.
- Настройки разнесены по файлам: базовые — в `lua/core` и подключаются вручную
  в `init.lua` в нужном порядке; плагины — автоматически из `plugin`; конфигурации LSP — автоматически из `after/lsp` и `lsp`: в первом случае настройки рекурсивно объединяются, во втором — переопределяются.
- По умолчанию добавлена поддержка только Lua и VimScript для удобства
редактирования конфига.
- Для установки языковых серверов используется Mason. Большинство из них
подхватываются автоматически. Он так же может устанавливать форматеры и линтеры. Если, например, редактор ругается на отсутствие `shfmt`, то его можно установить из интерфейса Mason либо через команду `:MasonInstall shfmt`. Все средства разработки ставятся в `~/.local/share/nvim/mason/packages`. Для удобства  добавлено сочетание `<leader>m` для запуска Mason. 
- Для форматирования используется `conform.nvim`. Его применение оправдано тем,
что не все средства форматирования работают через LSP + преждопределенные настройки через `nvim-treesitter` могут конфликтовать между собой. Используйте команду `:ConformInfo` для вывода отладочной информации о используемых LSP и средствах форматирования.
- Установлен `wrap=false` для всех типов буферов кроме текстовых и markdown. Нужно полагаться на форматирование через LSP, а не на то что файл откроют в редакторе с нужными настройками.
- Treesitter (встроен) отвечает за улучшенную подсветку (она и без него может
работать), сворачивание блоков, переименование объектов и т.п. Плагин `nvim-treesitter` предоставляет команду `TSInstall`, через которую можно установить недостающие парсеры, либо можно поставить их все: `:TSInstall all`. Парсеры автоматически обновляются при обновлении плагина, но он довольно редко обновляется, поэтому периодически можно вручную вызывать `:TSUpdate`.
- В качестве файлового менеджера используется `oil.nvim`, позволяющий создавать, переименовывать и удалять файлы прямо в буфере.
- Для поиска по файлам и их содержимому используется `fzf-lua`. Для этого установите fzf и ripgrep.
- Для работы с git добавлен `neogit`. Я сам им редко пользуюсь... Мне больше по
  старинке нравится: `git commit -am`, `git push` из терминала. 
- Добавлены автоматическое закрытие кавычек, отображение отступов и выделение
  текущего блока кода. Названия цветов и их hex-коды отображаются с соответствующим фоном, что особенно полезно при работе с фронтендом.
- Требуется Nerd Font для отображения иконок и других специальных символов. У меня на скринах `JetBrains Mono`. Его nerd-версия есть в стандартном репозитории арча.
- Я не стал добавлять глобальные поиск и замену по файлам. `grn` и `:argdo` прекрасно
справляются с этой задачей. Нету тут и отладчика — лишь минимум плагинов. Этот конфиг можно взять за основу своего и добавить недостающее. Я же вдохновлялся `helix`, которым, к слову, пользоваться неанглоязычным пользователя неудобно. Там нет встроенных раскладок, из-за чего сочетания системную раскладку нужно постоянно менять так как на русской не работают сочетания, не говоря уже об отсутствии мощной системы плагинов — там их кот наплакал. Там для настройки используется лишь `yaml`, что делает невозможной кастомизацию. Поэтому из него не сделать полноценную IDE. Про баги молчу. Vim же игнорирует современные стандарты типа поддержки LSP, DAP, treesitter — общепризнанных стандартов. Вместо этого его ныне покойный разработчик добавил какие-то политические призывы.
