### Описание

Минималистичный конфиг Neovim 0.12+ со сл. особенностями:

- Использует встроенный пакетный менеджер `vim.pack`.
- Настроены встроенные LSP и автодополнение.
- Сочетания клавиш не конфликтуют с Zellij. Единственное, что придётся
  переопределить, — это `<C-g>`, часто использующееся в Vim и других консольных приложениях, на какое-нибудь другое с Alt (встроенных сочетаний с Alt в Neovim нет).
- Решает проблему с комбинациями, перестающими работать при переключении
  системной раскладки, путём использования встроенной русской раскладки (`Ctrl` + `6` в режиме вставки для переключения).
- Доступные комбинации показываются при вводе части префикса; полный список
  открывается по `<leader>?` (через `which-key.nvim`).
- Для leader используется пробел.
- Настройки разнесены по файлам: базовые — в `lua/config` и подключаются вручную
  в `init.lua` в нужном порядке; плагины — автоматически из `plugin`; конфигурации LSP — автоматически из `after/lsp` и `lsp`: в первом случае настройки рекурсивно объединяются, во втором — переопределяются.
- Для установки языковых серверов используется Mason. Большинство из них
  подхватываются автоматически. Он так же может устанавливать форматеры и линтеры. Если, например, редактор ругается на отсутствие `shfmt`, то его можно установить из интерфейса Mason либо через команду `:MasonInstall shfmt`.
- Поддерживаются языки: Bash, Lua, Vim, Python, TypeScript/JavaScript, Go, HTML/CSS и другие.
- Для форматирования используется `conform.nvim`. Его применение оправдано тем, что не все средства форматирования работают через LSP.
- Установлен `wrap=false` для всех типов буферов кроме текстовых и markdown. Нужно
  полагаться на форматирование через LSP, а не на то что файл откроют в редакторе с нужными настройками.
- Для возможностей Treesitter (подсветка, сворачивание и т.п.) при первом
  запуске нужно выполнить `:TSInstall all` либо установить только нужные парсеры.
  Парсер обновляются автоматически при обновлении `nvim-treesitter`.
- В качестве файлового менеджера используется `oil.nvim`, позволяющий создавать, переименовывать и удалять файлы прямо в буфере.
- Для поиска по файлам и их содержимому используется `fzf-lua`. Для этого установите fzf и ripgrep.
- Для работы с git добавлен `neogit`.
- Добавлены автоматическое закрытие кавычек, отображение отступов и выделение
  текущего блока кода. Названия цветов и их hex-коды отображаются с соответствующим фоном, что особенно полезно при работе с фронтендом.
- Требуется Nerd Font для отображения иконок и других специальных символов. У меня на скринах `JetBrains Mono`. Его nerd-версия есть в стандартном репозитории арча.
- Я не стал добавлять глобальные поиск и замену по файлам. `grn` прекрасно справляется с этой задачей. Нету тут и отладчика — лишь минимум плагинов. Этот конфиг можно взять за основу своего и добавить недостающее. Я же вдохновлялся `helix`, которым, к слову, пользоваться неанглоязычным пользователя неудобно. Там нет встроенных раскладок, из-за чего сочетания системную раскладку нужно постоянно менять так как на русской не работают сочетания, не говоря уже об отсутствии мощной системы плагинов — там их кот наплакал. Там для настройки используется лишь `yaml`, что делает невозможной кастомизацию. Поэтому из него не сделать полноценную IDE. Про баги молчу. Vim же с его марсиянским языком для конфигов и призывами на главной может идти в щель.
